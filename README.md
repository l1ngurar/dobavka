# Добавка

Веб-приложение для приёмки телефонов. Собирает IMEI в партии по поставщикам, сохраняет историю добавок и готовит XLSX для Hello Client. Из добавки можно скопировать краткую сводку с моделями, количеством и цветными сердечками.

## Быстрый старт

Скачайте [index.html](index.html) и [favicon.svg](favicon.svg) в одну папку и откройте `index.html` в браузере. Для проверки введите вымышленный 15-значный IMEI, например `123456789012345`. Сборка приложения не нужна.

1. Нажмите «Новая добавка» и введите название модели. Выберите память и цвет из подсказок или чипсов.
2. Отсканируйте IMEI или введите его вручную. Enter в поле сканирования добавляет номер, F2 возвращает туда фокус.
3. Нажмите «Следующая партия», чтобы перенести текущую партию в карточку поставщика. Для следующего поставщика используйте «+ Поставщик».
4. Сохраните добавку в истории, выгрузите XLSX или откройте текстовую сводку кнопкой с белым сердечком. Сводка сокращает название модели, убирает «iPhone» и «ГБ» и обозначает цвет сердечком.

Ctrl+E переключает отметку «Ошибка», когда действие доступно. Ctrl+K или Cmd+K открывает поиск.

## Данные и резервная копия

Черновик и история хранятся в браузере. У локального файла, `localhost` и домена отдельные хранилища. Перед сменой адреса страницы, браузера или компьютера скачайте JSON-копию средствами приложения. При восстановлении JSON текущий черновик и история в целевом браузере заменяются после подтверждения.

XLSX предназначен для передачи партий в Hello Client. Имена поставщиков остаются в истории приложения, а в XLSX группы поставщиков разделяются пустой строкой. Для переноса истории используйте JSON-копию. Реальные IMEI, рабочие XLSX и резервные копии храните вне публичного репозитория.

## Запуск на домашнем сервере

На сервере с Git, Docker и Docker Compose выполните:

```sh
git clone https://github.com/l1ngurar/dobavka.git ~/dobavka
cd ~/dobavka
docker compose up -d
docker compose ps
curl -fsS -o /dev/null http://127.0.0.1:8086/
```

[compose.yaml](compose.yaml) поднимает nginx на `127.0.0.1:8086`. Этот адрес доступен на самом сервере. Чтобы открыть приложение с других устройств через уже настроенный обратный прокси, направьте его на этот адрес. Пример блока для Caddy, работающего на хосте:

```caddy
dobavka.example.com {
    reverse_proxy 127.0.0.1:8086
}
```

Замените `dobavka.example.com` своим доменом. Раздача через nginx работает со статическими файлами, а черновики и история остаются в браузере. Выкладка на домашнем сервере пока не проверена.

Обновление из репозитория:

```sh
cd ~/dobavka
git pull --ff-only
docker compose up -d --force-recreate
curl -fsS -o /dev/null http://127.0.0.1:8086/
```

При ошибке запуска посмотрите состояние контейнера и последние сообщения:

```sh
docker compose ps
docker compose logs --tail=50
```
